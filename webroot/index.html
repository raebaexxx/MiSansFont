MiSans — font weight

The shift is written into the font configuration, so it reaches every app including the ones that pick a font outside TextView. The MiSans weight axis ends at 700 — it does not get heavier beyond that.
Takes effect after a reboot. The font configuration is read once at boot, there is no live update.
